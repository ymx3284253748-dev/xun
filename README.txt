Nebula Buds · 星云无线耳机

使用方法
1. 将整个 Nebula-Buds 文件夹解压到任意位置。
2. 双击 index.html，用 Chrome、Edge、Safari 或 Firefox 打开。
3. 产品页导航中的「星云日常」进入第二页，也可直接打开 community.html。

两个页面不需要安装软件、启动服务器或联网，所有脚本、样式、图形均保存在本文件夹。

产品页：毛玻璃吸顶导航、原生滚动叙事、三种配色、参数对比、购买演示面板。
品牌页：五屏手机轮播（支持触摸滑动、左右箭头、键盘方向键和指示点）、故事弹窗、点赞、收藏、评论、可暂停 Reels 动画、底部导航。

购买按钮仅保存所选颜色，不会产生订单或扣款。评论、点赞、收藏用于本地演示，评论仅保留在本次浏览中。
这是虚构品牌的原创网站设计演示，产品参数、价格、服务承诺均为演示设定，与 Apple 或 Instagram 无关联。

维护
tokens.css 是两页共用的颜色、圆角、字号与字体 token。
product-art.js 包含自绘 SVG 耳机；全部滚动交互使用 IntersectionObserver 和原生 JavaScript。
product.css / product.js 控制产品页；community.css / community.js 控制品牌页。
common.js 控制共享配色、导航和购买面板。
无需构建工具、框架、第三方动画库或 CDN。
